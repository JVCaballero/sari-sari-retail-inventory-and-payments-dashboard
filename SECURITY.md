# Security Policy

## Supported Versions

Since this project is currently under active development, security updates are only provided for the latest code on the `main` branch and the most recent release tag.

| Version | Supported |
| ------- | --------- |
| `main` / Latest Tag | :white_check_mark: |
| < Latest Tag | :x: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a potential security flaw in this repository, please report it privately:

* **GitHub Private Vulnerability Reporting (Preferred):** Go to the **Security** tab of this repository, select **Advisories** on the left menu, and click **Report a vulnerability**.
* **Direct Contact:** If private reporting is disabled, send an email to `alesanesa1@gmail.com` with the subject line `[SECURITY] Potential Vulnerability`.

### What to Include in Your Report
* Description of the vulnerability and its potential impact.
* Clear steps or a proof-of-concept (PoC) script to reproduce the issue.
* Any potential fixes or mitigations you recommend.

### Response Time & Expectations
* **Acknowledgement:** You will receive an initial response acknowledging your report within **48 hours**.
* **Assessment:** We will investigate and notify you whether the report is accepted or declined within **7 business days**.
* **Resolution:** If confirmed, a fix will be pushed to the `main` branch as soon as possible, and you will be credited in the release notes (unless you prefer to remain anonymous).
