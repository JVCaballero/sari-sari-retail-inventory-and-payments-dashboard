# TindaHalin - Giya sa Paggamit (Cebuano / Bisaya)

## 1. Pagpabaligya (Bag-ong Baligya)
- I-tap ang **Sell (Pabaligya)** sa ubos nga bar.
- I-tap ang mga produkto o sud-an aron maapil sa karton.
- I-tap ang **Checkout** -> pilia ang **Kwarta (Cash)** -> ibutang ang **Kwarta nga nadawat**.
- Tan-awa ang **Sukli** ug i-tap ang **I-save (Complete Sale)**!

## 2. Paggamit sa QR Ph Code
- Ipakita ang QR Ph code sa tindahan.
- Siguroha nga nadawat ang SMS/Notification sa cellphone sa tindahan sa dili pa i-confirm.
- Ibutang ang reference number suffix kon kinahanglan.

## 3. Utang sa Suki
- Sa Checkout, pilia ang **Utang** -> pilia ang ngalan sa suki.
- Tan-awa ang balanse sa **Utang Ledger**.

## 4. Pagsirado sa Adlaw (Close Day)
- Sa **Today (Halin Karon)** -> i-tap ang **Sirado ang Adlaw**.
- Isipon ang kwarta sa drawer ug i-check ang halin karong adlawa.
