# TindaHalin - User Guide (English)

## 1. Quick Sale
- Tap **Sell** in the main navigation.
- Tap product cards or search to add items to cart.
- Tap **Checkout** -> select **Cash** -> enter amount received -> view exact **Change** ("Sukli").
- Tap **Complete Sale**. Stock updates automatically!

## 2. QR Ph Collections
- Show store QR code on customer's phone.
- Confirm payment notification on store phone before clicking **Payment Received**.
- Optionally record reference suffix.

## 3. Utang (Credit Ledger)
- In checkout, select **Credit (Utang)** -> select customer name.
- Track running balances in Utang screen.

## 4. Closing the Day
- Go to **Today** -> tap **Close Day**.
- Count cash drawer money, enter total, view sales breakdown and variance.
